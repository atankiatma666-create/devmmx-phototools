About devMmX PhotoTools

devMmX PhotoTools is a small website for one everyday problem: getting a photo under an upload size limit.

Who runs it

devMmX PhotoTools is run by Sem. You can reach us through the contact page.

What is here today

There is one tool, Compress Image to a Target KB, and two guides that explain reducing photo size on Android and dimensions versus file size. More tools may be added later, but only when they work properly.

How it works

The site is a set of plain web pages. The compressor runs in your browser using the built-in canvas feature: it draws your image and asks the browser to save it as a JPEG at different quality settings, then keeps the best one under your limit. Your photo is not sent to a server. The pages include a security setting that stops them from sending data to other addresses.

What we do not claim

devMmX PhotoTools is not connected with any government, exam board, passport office or employer. We cannot promise that a particular form will accept a photo, because each form has its own rules. The site currently shows no advertising and uses no analytics.
